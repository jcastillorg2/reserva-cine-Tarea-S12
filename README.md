# Reserva de un asiento en sala de cine

Johanna Lucia Castillo Rodriguez

## Objetivo del programa

Desarrollar un programa en Python que permita reservar un asiento de una sala de cine de 3 filas por 4 columnas, utilizando una matriz representada mediante listas anidadas.

El programa solicita al usuario la fila y la columna del asiento que desea reservar, cambia el valor de ese asiento de 0 a 1 y finalmente muestra el estado completo de la sala mediante bucles anidados.

## Representación de los asientos

0 = asiento libre
1 = asiento reservado

La sala está organizada por:
3 filas × 4 columnas

## ¿Cómo ejecutar el programa?

1. Tener Python instalado en el computador.
2. Descargar o clonar este repositorio.
3. Abrir una terminal en la carpeta donde se encuentra el archivo.
4. Ejecutar el siguiente comando:

python reserva_cine.py

O tambien:
py reserva_cine.py
